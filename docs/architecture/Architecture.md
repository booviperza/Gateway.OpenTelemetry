# Gateway.OpenTelemetry Architecture

Version

1.0

Status

Draft

---

# 1. Overview

Gateway.OpenTelemetry is an extension framework for
OpenTelemetry.

It never generates telemetry.

It enriches telemetry generated by existing
OpenTelemetry Instrumentation.

---

# 2. Design Goals

- Native OpenTelemetry

- Vendor Neutral

- Zero Custom Metrics

- Zero Custom Traces

- Plugin Architecture

- ASP.NET Core First

---

# 3. High Level Architecture

                Application
                      │
                      ▼
        OpenTelemetry Instrumentation
                      │
        ┌─────────────┴─────────────┐
        │                           │
        ▼                           ▼
 AspNetCore Tracing          AspNetCore Metrics
        │                           │
        ▼                           ▼
     Gateway.OpenTelemetry.AspNetCore
        │
        ▼
     Gateway.OpenTelemetry.Core
        │
        ▼
          Exporters

Gateway.OpenTelemetry does not own exporters.

Applications configure exporters.

# 6. Core Responsibilities

Core contains

- Contracts

- Constants

- Options

- Utilities

Core never references

- ASP.NET Core

- YARP

- Hosting

- Dependency Injection

---

# 7. AspNetCore Responsibilities

AspNetCore contains

- ASP.NET Integration

- Trace Tag Enrichers

- Metric Tag Enrichers

- Registration

AspNetCore never creates telemetry.

---

# 8. YARP Responsibilities

YARP contains

- Route Tags

- Cluster Tags

- Destination Tags

YARP depends on AspNetCore.
